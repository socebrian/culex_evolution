# Evolution of Culex species: phylogeny, synteny and comparetive genomics

This repository contains the data and code used in the study of the evolution of Culex species through phylogenetic analysis, synteny mapping, and comparative genomics. The project aims to understand the genetic relationships and evolutionary history of various Culex mosquito species.

You can find the Data Management Plan for this project in the file: [DMP_BGE_Culex_WNV_v1.md](DMP_BGE_Culex_WNV_v1.md).
